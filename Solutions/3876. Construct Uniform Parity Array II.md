# [3876. Construct Uniform Parity Array II](https://leetcode.com/problems/construct-uniform-parity-array-ii)

<!-- description:start -->

<p>You are given an array <code>nums1</code> of <code>n</code> <strong>distinct</strong> integers.</p>

<p>You want to construct another array <code>nums2</code> of length <code>n</code> such that the elements in <code>nums2</code> are either <strong>all odd or all even</strong>.</p>

<p>For each index <code>i</code>, you must choose <strong>exactly one</strong> of the following (in any order):</p>

<ul>
    <li><code>nums2[i] = nums1[i]</code>​​​​​​​</li>
    <li><code>nums2[i] = nums1[i] - nums1[j]</code>, for an index <code>j != i</code>, such that <code>nums1[i] - nums1[j] &gt;= 1</code></li>
</ul>

<p>Return <code>true</code> if it is possible to construct such an array, otherwise return <code>false</code>.</p>
<p>&nbsp;</p>

<p><strong class="example">Example 1:</strong></p>
<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">nums1 = [1,4,7]</span></p>
<p><strong>Output:</strong> <span class="example-io">true</span></p>
<p><strong>Explanation:</strong>​​​​​​​​​​​​​​</p>
<ul>
    <li>Set <code>nums2[0] = nums1[0] = 1</code>.</li>
    <li>Set <code>nums2[1] = nums1[1] - nums1[0] = 4 - 1 = 3</code>.</li>
    <li>Set <code>nums2[2] = nums1[2] = 7</code>.</li>
    <li><code>nums2 = [1, 3, 7]</code>, and all elements are odd. Thus, the answer is <code>true</code>.</li>
</ul>
</div>

<p><strong class="example">Example 2:</strong></p>
<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">nums1 = [2,3]</span></p>
<p><strong>Output:</strong> <span class="example-io">false</span></p>
<p><strong>Explanation:</strong></p>
<p>It is not possible to construct <code>nums2</code> such that all elements have the same parity. Thus, the answer is <code>false</code>.</p>
</div>

<p><strong class="example">Example 3:</strong></p>
<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">nums1 = [4,6]</span></p>
<p><strong>Output:</strong> <span class="example-io">true</span></p>
<p><strong>Explanation:</strong></p>
<ul>
    <li>Set <code>nums2[0] = nums1[0] = 4</code>.</li>
    <li>Set <code>nums2[1] = nums1[1] = 6</code>.</li>
    <li><code>nums2 = [4, 6]</code>, and all elements are even. Thus, the answer is <code>true</code>.</li>
</ul>
</div>
<p>&nbsp;</p>

<p><strong>Constraints:</strong></p>
<ul>
    <li><code>1 &lt;= n == nums1.length &lt;= 10<sup>5</sup></code></li>
    <li><code>1 &lt;= nums1[i] &lt;= 10<sup>9</sup></code></li>
    <li><code>nums1</code> consists of distinct integers.</li>
</ul>
<p>&nbsp;</p>

## Solutions

### **Approach 1: Case Analysis**

This problem is similar to "3875. Construct Uniform Parity Array I", but with an additional constraint: when using the second operation, it must satisfy $\textit{nums1[i]}$ - $\textit{nums2[i]}$ $\geq 1$, meaning the minuend must be strictly greater than the subtrahend.

Since only subtracting an odd number changes the parity (even minus odd gets odd, odd minus odd gets even), we only need to focus on the minimum odd number in the array.

Let the length of $\textit{nums1}$ be $n$, and the minimum value in the array be $mini$. Since the minimum value cannot be changed by subtracting a smaller number, the parity of $mini$ determines the target parity of $\textit{nums2}$.

We classify $\textit{nums1}$ into discussions:

1. $\textit{nums1}$ is all even: In this case, we can directly set each $\textit{nums2[i]}$ = $\textit{nums1[i]}$ (using the first operation), and the resulting $\textit{nums2}$ will all be even, satisfying the condition.

2. $\textit{nums1}$ is all odd: Similarly, we can directly set each $\textit{nums2[i]}$ = $\textit{nums1[i]}$, and the resulting $\textit{nums2}$ will all be odd, satisfying the condition.

3. $\textit{nums1}$ contains both odd and even numbers:

- If $mini$ is odd: We can construct the array to be all odd. For odd positions, use the first operation directly; for even positions, let the even number subtract $mini$ (a smaller odd number), since even minus odd gets odd, and $mini$ is the minimum value, any even number subtracting $mini$ will result in a number $\geq 1$ , satisfying the problem's requirements.

- If $mini$ is even: It is impossible to construct a valid $\textit{nums2}$. Because:

    - If the goal is to be all even: The odd number must subtract an odd number to become even. But the smallest odd number cannot find a smaller odd number to subtract, so the parity cannot be changed.

    - If the goal is to be all odd: The even number $mini$ must subtract an odd number to become odd. But $mini$ is the minimum value, and there is no smaller number to subtract.

    Both cases are infeasible, so return $\text{false}$.

In summary, we only need to traverse the array once, find the minimum value $mini$, and record whether there is an odd number:

If $mini$ is odd, return $\text{true}$ directly.

If $mini$ is even, return $\text{true}$ only if there are no odd numbers in the array, otherwise return $\text{false}$.

The time complexity is $O(n)$, and the space complexity is $O(1)$.

<p><strong>Time Complexity:</strong> $O(n)$</p>
<p><strong>Space Complexity:</strong> $O(1)$</p>

<!-- tabs:start -->

```java
class Solution {
    public boolean uniformArray(int[] nums1) {
        int mini = nums1[0];
        boolean hasOdd = false;
        
        for (int v : nums1) {
            mini = Math.min(mini, v);
            
            if ((v & 1) == 1) {
                hasOdd = true;
            }
        }
        
        // If mini is odd, return true directly
        if ((mini & 1) == 1) {
            return true;
        }
        
        // If mini is even, return true only if there are no odd numbers in the array, otherwise return false
        return !hasOdd;
    }
}
```
